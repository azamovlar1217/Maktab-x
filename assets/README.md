# MAKTAB X visual assets

These original assets are used by the Next.js public site. The PNG illustrations were generated for this project and then copied to `public/assets` for serving.

| File | Use | Dimensions |
| --- | --- | --- |
| `x-mascot.svg` | Small MAKTAB X brand mark | 220 × 240 |
| `x-robot.png` | Animated floating robot illustration, login and invite visuals | 1145 × 1374 |
| `student-boy.png` | Portal welcome illustration | 1024 × 1536 |
| `student-girl.png` | Public role illustration | 1024 × 1536 |
| `school-hero.png` | Landing page school scene and poster fallback | 1536 × 1024 |

Video and audio prompts are in `video-audio-prompts.md`. Final approved video and music files have not been generated. A video URL can be supplied using `NEXT_PUBLIC_HOME_VIDEO_URL`; the landing page keeps the still scene and animated robot visible if no video URL is set. Music never autoplays.
